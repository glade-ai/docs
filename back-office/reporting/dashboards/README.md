# Dashboards

## Overview

Alongside the personal dashboard each person sees on their own homepage, a firm can build **named dashboards** that everyone at the firm shares. Both are built from widgets. A new team member's homepage starts with a default set of widgets, and a firm can choose one named dashboard as its **default homepage**, shown live on every member's homepage.
