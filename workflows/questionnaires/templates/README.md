# Building Templates

## Overview

A questionnaire template defines the structure of a form — its sections, fields, validation, conditional logic, and how answers map onto generated court forms. Your firm's template administrator builds and publishes templates; every questionnaire is created from the current version of one.

## Topics

- [Template Settings](./template-settings.md) — versions, sections, assignees, tags, inheritance, reminders, review workflow, AI summary, and form provider.
- [Fields, Lists, and Tables](./fields-and-tables.md) — field types, select options, linked and referenced fields, table columns, and flipping a table.
- [Validation Rules](./validation-rules.md) — field validation, rules on table and list cells, and rules whose answers are still blank.
- [Conditional Visibility](./conditional-visibility.md) — showing and hiding sections and fields, including conditions on currency fields.
- [PDF Fill Mappings](./pdf-fill-mappings.md) — mapping fields to PDFs, supplemental forms, pagination, and whole-dollar totals.

Autofills are configured on the template too — see [Autofills](../autofills/README.md).
